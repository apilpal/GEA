# Archive

Documents kept for history. They are **not maintained** and may describe features that no
longer exist.

- `guest-dashboard/` - the guest user and guest dashboard, which were removed from the app.
- `documentation/` - old documentation hubs and plans from earlier restructures.
- `duplicates/` - near-duplicate versions of pages that now live elsewhere in `docs/`
  (for example an older architecture overview or user stories). The current versions are
  linked from the [documentation index](../README.md).
- `styling/` - SCSS change logs and summaries.

Nothing here is needed to run or develop the app.
